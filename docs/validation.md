# 续页 v1.0 验收与故障复盘

2026 年 11 月 26 日，测试使用 v1.0 的应用代码。真实模型通过 RelayCore 调用 `deepseek-v4.1-flash-1017`。书籍是 Bookstacks 321 页英文版《傲慢与偏见》。

## 一个可以讲清楚的故障

录制初次由第 168 页推进到第 169 页时，页面显示新的书签，但同题回答仍询问是否查看后文。模型已经收到书签附近的原文，审校接受的事实为零。最终状态为 `limited`，原代码只会对 `unknown` 或部分澄清场景再检索一次，当前请求因此提前结束。

修订把较早书签下找不全证据的同题回答和本轮新书签联系起来。模型先检查新位置附近的原文。如果仍判证据不足，系统在本轮书签内再核对一次。读者的实际书签和单题授权状态继续由后端决定。

复测时，同一个浏览器里退回第 168 页再推进，重新提交同一句问题。第二次得到有原文依据的解释，给出了达西来信里威克姆放弃圣职、改收三千镑的说法。也验证了推进后可点开原文，回退后超前卡片和引文一起收起。

另一次要求把最初说法、来信和反应一起串起来的追问，没有给出完整答复，属于内容未通过。后续两次重跑出现网关连接中断，表现为 502。采用上表的聚焦问法复测通过。这次验收确认了所列场景的行为，复杂问法和网关延迟仍存在波动。
